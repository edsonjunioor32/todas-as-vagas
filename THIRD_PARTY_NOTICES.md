# Créditos de componentes adaptados

O pipeline multiportal deriva da estrutura do **Job-Market Explorer**, de Rodrigo Carvalho:

https://github.com/rodrigo-carfon/rodrigo-carfon.github.io/tree/master/jobs-dashboard

O projeto de origem foi dedicado ao domínio público por meio da **Unlicense**. Os adaptadores, a normalização, o armazenamento SQLite e a exportação compacta foram modificados para este painel.

As marcas e os nomes dos portais pertencem a seus respectivos titulares. Este projeto apenas indexa metadados encontrados em interfaces públicas e direciona o usuário ao anúncio original.

Oracle, Oracle Cloud e Oracle Recruiting Cloud são marcas da Oracle Corporation. O projeto consulta somente metadados expostos pela página pública de experiência da pessoa candidata e não possui vínculo com a Oracle nem com as empresas listadas.

Greenhouse é marca de Greenhouse Software, Inc. O projeto consulta apenas os metadados públicos do Job Board API. A descoberta periódica de identificadores usa como insumo um catálogo público do projeto Job Board Aggregator; o catálogo derivado incluído neste pacote contém somente empresas confirmadas com vagas no Brasil e não redistribui a lista original completa.
